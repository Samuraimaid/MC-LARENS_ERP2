## Backup & Archive Strategy

### Local Backups

**When**: Before each major phase (before Phase 5 cleanup)

```bash
# Full backup before Phase 5
BACKUP_DATE=$(date +%Y%m%d_%H%M%S)
7z a "repo_backup_${BACKUP_DATE}.7z" . \
  -x'!.git' \
  -x'!.venv' \
  -x'!frontend/node_modules' \
  -x'!backend/__pycache__'

# Result: ~100-150MB backup (excluding regenerables)
```

For historical/archaeological artifacts:


## Exclusion Rules for Common Scenarios

### Git Clone on New Machine

Ensure .gitignore prevents bloat on fresh clone:

```bash
# Fresh clone should only get:
git clone <repo>
cd <repo>

# Check what was cloned
du -sh .   # Should be < 50MB (mostly source code + .git)

# Dependencies regenerate on demand:
npm --prefix frontend ci    # ~200MB (temporary)
python -m venv .venv && pip install -r requirements.txt  # ~50MB
```

### Docker Deployments

Reduce Docker context by excluding regenerables:

```bash
# Current build context (with artifacts)
du -sh frontend/ backend/   # ~400MB (includes node_modules, build, __pycache__)

# After .dockerignore optimization
# Expected: ~100MB (source code only)

# Benefit: Faster upload to registries (3-5x speedup)
```

### CI/CD Pipeline

Prevent bloat in CI artifacts:

```bash
# GitHub Actions example
- name: Build

      --build-arg VITE_BACKEND_URL=... \
      frontend

# .dockerignore ensures:
# - node_modules NOT included in context (regenerated with npm ci)
# - __pycache__ NOT included

```

## Prevention Strategy: Detecting Future Bloat

### Pre-Commit Hook (Optional)

Detect when regenerable files are about to be committed:

```bash
#!/bin/bash
# .git/hooks/pre-commit

# Check for accidentally added node_modules
if git diff --cached --name-only | grep -q "node_modules/"; then
  echo "ERROR: node_modules/ detected in staging area"
  echo "Use: git reset frontend/node_modules"
  exit 1
fi

# Check for __pycache__
if git diff --cached --name-only | grep -q "__pycache__"; then
  echo "ERROR: __pycache__/ detected in staging area"
  echo "Use: git reset backend/__pycache__"
  exit 1
fi

# Check for .venv
if git diff --cached --name-only | grep -q "\.venv"; then
  echo "ERROR: .venv detected in staging area"
  echo "Use: git reset .venv"
  exit 1
fi
```

### Repository Size Monitoring

```bash
# Check current repo size (excluding .git)
du -sh . --exclude=.git

# Expected after Phase 5: ~50-100MB

# Monitor growth over time
git log --all --oneline --graph | head -20
git rev-list --all --objects | sort -k2 | tail -10  # Largest objects
```

## .gitignore vs .dockerignore Summary

| Ignore Type | Purpose | When Applied | Impact |
|-------------|---------|--------------|--------|
| **.gitignore** | Prevent bloat in git history | On commit | Saves git history size |
| **.dockerignore** | Reduce Docker context | On docker build | Saves build time & upload |
| **Both** | Prevent regenerables | Development & CI | Cleaner repo + faster builds |
