# Paquete Antigravity — OCR Tarjeta de Circulación NI

## Qué hay aquí

1. `PROMPT_ANTIGRAVITY.md` — prompt completo para pegar en el chat de Antigravity.
2. `circulacion-ni-ocr/` — skill opcional (cópialo a la carpeta de skills de Antigravity si usas skills).

## Cómo usarlo

1. Abre `PROMPT_ANTIGRAVITY.md`.
2. Copia desde `INICIO DEL PROMPT` hasta `FIN DEL PROMPT`.
3. Pégalo en el chat de Antigravity con el repo `MC-LARENS_ERP2` abierto.
4. (Opcional) Copia `circulacion-ni-ocr/` a `.agent/skills/` o la ruta de skills que use tu Antigravity.

El prompt ya incluye todas las reglas. El skill es respaldo por si Antigravity carga skills del disco.
